# Daily Compass

Single-file task manager published as a claude.ai Artifact. It combines Toptal, practice, content, people, joy and body tasks in one place.

- `compass.html` is the page body. Tasks, goals, plans, daily reflections, settings and the coach log are saved with the artifact `db` capability, with a localStorage fallback.
- Today: Big 3 (max three), a "something for you" slot, load vs. daily capacity, weekly balance with protected hours for joy, people and body, and an avoidance radar for tasks moved 2 or more times.
- Plan: inbox, scheduled days, someday. Goals: each goal shows its next step or flags it as stalled, and "Break it down" proposes schedulable steps.
- Coach: chat through the `sample` capability. It sees tasks, goals, balance and reflections, pushes back on motives, and can add tasks, schedule them and save week or month focus.
- Items marked "example" were seeded for the first view. Settings has "Clear example data".

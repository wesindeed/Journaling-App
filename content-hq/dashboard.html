Tag a link to a video

Adds UTM tags so Google Analytics can tell which video sent the click. See the caveat below for Kit and ThriveCart pages.

Google Analytics reads UTM tags only on pages where your GA tag runs, such as your Squarespace site. Kit and ThriveCart pages sit on their own domains. For those, the dependable route is one Kit form or tag per video call-to-action, and a ThriveCart link or coupon per video. Check what your plan supports before relying on UTM pass-through.

Getting your two Claude chats into the dashboard

Project chats are not readable by any connector available here, so the dashboard cannot see them directly. A shared table fixes that: the chat writes the schedule, the dashboard reads it.

  1. Paste the prompt below at the end of each scheduling chat.
  2. Paste the table it returns into a Notion database called "Content Calendar" (Notion is already connected to this session).
  3. The dashboard reads that database instead of the Drive folder, so stages and dates come from the chats.
Output our current content calendar as a table with these columns: Title | Format (Long or Short) | Target publish date (YYYY-MM-DD) | Stage (Research, Scripted, Filmed, Editing, Thumbnail and title, Scheduled, Published) | Primary keyword | Script link | Lead magnet or course CTA. One row per video, soonest first.

Why the business tools take a middle layer

A page like this cannot safely hold API keys for Kit, ThriveCart or Google Analytics. Two clean ways to connect them:

  1. Zapier or Make into a Google Sheet. New Kit subscriber, ThriveCart purchase and a daily GA4 export each append a row. This dashboard reads the Sheet through the Drive connector that is already connected. Lowest effort.
  2. A connector for each tool. Cleaner and live, but needs a Kit or GA4 connector added to your Claude account, which is not there today.
